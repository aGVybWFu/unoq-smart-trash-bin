# ♻️ 智慧垃圾分類回收桶 (Smart Recycling Trash Bin)

## 1. 專案概述

本專案基於 **Arduino Uno Q** 構建智慧垃圾分類回收桶。透過 AI 攝影機即時辨識塑膠和紙杯，自動控制舵機傾斜分流平台，將垃圾導入對應的回收桶，並在網頁儀表板上即時顯示回收統計數據。

**核心亮點**：
* **AI 視覺辨識**：即時偵測塑膠瓶和紙杯
* **自動分類**：單舵機分流平台，待機時水平穩定，辨識後自動傾斜分類
* **網頁儀表板**：即時顯示回收統計、圓餅圖、分類歷史記錄
* **手動測試模式**：無需實體垃圾即可模擬分類流程
* **弱網自動重連**：內建斷網重連機制

## 3. 硬體架構與接線

| 組件 | 型號 | Arduino 引腳 | 說明 |
|------|------|-------------|------|
| 主控 | Arduino Uno Q | - | 基於 STM32/Zephyr |
| 分流舵機 | MG996R (0-180°) | D11 | 控制分流平台傾斜方向 (手動 PWM) |
| 攝影機 | USB Cam | USB Port | AI 視覺辨識用 |

### 舵機角度定義
| 角度 | 狀態 | 說明 |
|------|------|------|
| 90° | 水平待機 | 平台保持穩定，等待垃圾 |
| 30° | 塑膠分類 | 平台向左傾斜，垃圾滑入塑膠桶 |
| 150° | 紙杯分類 | 平台向右傾斜，垃圾滑入紙杯桶 |

## 4. 軟體架構

### 4.1 前端 (Assets)
- **儀表板**：頂層「專案報告 / 控制台」切換；控制台含 總覽(統計+影像) / 歷史記錄 / 系統控制 子頁籤
- **即時統計**：塑膠/紙杯計數、總數、動畫圓餅圖
- **分類記錄**：歷史記錄查詢 SQLite（分頁+篩選），最新的在最上面
- **手動測試**：「模擬塑膠」和「模擬紙杯」按鈕

### 4.2 中台 (Python)
- **AI 辨識**：偵測 plastic_cup/plastic/container → 塑膠類；paper_cup/paper/mug/cup → 紙杯類
- **冷卻機制**：每次分類後 5 秒冷卻，防止重複辨識
- **資料持久化**：分類記錄寫入 SQLite（`sort_records`），重啟後統計自動恢復
- **統計管理**：維護計數器，透過 Socket 推送；歷史由前端 `db_query_*` 頻道查詢

### 4.3 底層 (Arduino)
- **狀態機**：IDLE(待機) → TILTING(傾倒) → RETURNING(回正)
- **回正機制**：傾倒後直接設定回 90° 水平位，等待 500ms 完成動作
- **傾倒時間**：維持 1.5 秒讓垃圾滑落

## 5. 操作說明

瀏覽器存取 `http://<設備IP>:7000` 進入儀表板。

### 📊 統計面板 (左欄)
- 顯示塑膠和紙杯各自的回收數量
- 總回收數量與圓餅圖比例

### 📷 影像面板 (中欄)
- 即時攝影機畫面
- AI 辨識結果 HUD 顯示
- 分類時顯示覆蓋提示動畫
- 手動測試按鈕：位於「系統控制」頁籤
- 清除統計按鈕：位於「系統控制」頁籤，重置所有計數

### 📋 記錄面板 (歷史記錄頁籤)
- 每次分類的時間和類型
- 最新記錄在最上面，分頁顯示（每頁 10 筆）
- 熱力圖顯示每日活動量

## 6. 快速啟動

1. 將 `sketch/` 目錄下的韌體上傳至 Arduino (或複製到 Arduino App Lab)
2. 確保 `assets/` 目錄下有所有前端檔案
3. 執行 Python 服務：
   ```bash
   python3 python/main.py
   ```

享受你的智慧垃圾分類回收桶！♻️
